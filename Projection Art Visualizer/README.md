# Kinect Projection Art Visualizer

An elegant, modular system for creating visually arresting projection art using Azure Kinect body tracking data.

## Features

### Current Visualizations

#### 1. Particle Flow Field ✨
Thousands of particles flow through animated force fields generated by Perlin noise. Body movements create repulsion zones, pushing and shaping the particle flows in real-time.

**Key characteristics:**
- 1,000 - 50,000 particles (configurable)
- Perlin noise-based flow field animation
- Body joints create force wells
- Multiple color modes: velocity-based, position-based, white, rainbow
- Smooth trail effects
- Highly performant (60fps)

## Architecture

The system is built with modularity in mind, making it easy to add new visualizations and switch between them in real-time.

### Core Components

```
BaseVisualization (abstract class)
├── init()          - Initialize visualization
├── update()        - Update state each frame
├── render()        - Draw to canvas
├── updateBodies()  - Receive Kinect data
└── updateParams()  - Adjust parameters

ParticleField (extends BaseVisualization)
├── Particle flow field implementation
└── 5000+ particles by default

VisualizationManager
├── switchMode()    - Hot-swap between visualizations
├── update()        - Update current viz
└── render()        - Render current viz
```

### Adding New Visualizations

1. Create a new class extending `BaseVisualization`
2. Implement required methods: `init()`, `update()`, `render()`
3. Add to `visualizations` registry in `visualizers.js`
4. Add option to `#viz-mode` dropdown in `index.html`

Example:
```javascript
class MyVisualization extends BaseVisualization {
    init() {
        // Setup visualization
    }

    update(deltaTime) {
        // Update state
    }

    render() {
        // Draw to this.ctx
    }
}
```

## Data Sources

### 1. Mock Data (Testing)
Simulated body with animated joints - perfect for development without Kinect hardware.

### 2. Mouse Input
Your mouse position becomes hand tracking - great for quick testing and demos.

### 3. Live Kinect
Connects to WebSocket server (ws://localhost:8080) streaming Azure Kinect body tracking data.

**Requires**: Kinect Bridge application running (see Kinect AI Sound Sculpture project)

## Controls

### Keyboard Shortcuts
- **H** - Toggle control panel visibility

### Parameters (Particle Field)
- **Particle Count** - Number of particles (1k - 50k)
- **Force Strength** - Intensity of forces
- **Flow Speed** - Animation speed of flow field
- **Particle Size** - Render size of particles
- **Trail Length** - Persistence of particle trails (0 = none, 0.99 = long)
- **Color Mode** - Velocity, Position, White, Rainbow

## Quick Start

### Option 1: Static HTML Server
```bash
cd "Projection Art Visualizer"
python -m http.server 8000
```
Open http://localhost:8000

### Option 2: With Kinect Integration
1. Start the Kinect Bridge app from "Kinect AI Sound Sculpture" project
2. Open `index.html` in browser
3. Select "Live Kinect" from Data Source dropdown
4. Move in front of Kinect

### Option 3: Browser Direct
Simply open `index.html` directly in a modern browser. Use Mock Data or Mouse Input mode.

## Performance

- Target: 60 FPS at 1920x1080
- Optimizations:
  - Efficient particle updates using object pooling
  - Flow field computed on grid (not per-particle)
  - Trail effects using alpha compositing
  - Minimal DOM manipulation

## Installation Space Considerations

### Projection Setup
- **Resolution**: Tested at 1920x1080, scales to any resolution
- **Refresh Rate**: 60Hz recommended
- **Mounting**: Browser in fullscreen (F11), hide cursor
- **Lighting**: Works in ambient light (Kinect uses infrared)

### Kinect Placement
- Mount 6-8 feet high
- Angle slightly downward
- 10' x 10' minimum tracking area
- Can track up to 5 people simultaneously

## Customization

### Aesthetic Tuning

Edit `ParticleField.js` parameters for different looks:

```javascript
// More organic, flowing
this.noiseScale = 0.005;  // Larger patterns
this.params.flowSpeed = 0.3;  // Slower movement
this.params.trailLength = 0.98;  // Longer trails

// More chaotic, energetic
this.noiseScale = 0.02;  // Tighter patterns
this.params.flowSpeed = 1.5;  // Faster movement
this.params.trailLength = 0.9;  // Shorter trails
```

### Color Schemes

Add custom color modes in `getParticleColor()`:

```javascript
case 'custom':
    const hue = (particle.pos.y / this.height * 180 + 200) % 360;
    return `hsla(${hue}, 100%, 50%, 0.9)`;
```
